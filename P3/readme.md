Habría que hacer algo más directo para el cliente, que esté menos cargado y que también tenga la resolución adecuada para poder subirse a Instagram.

### 3.c Guidelines
![Método UX](img/guidelines.png) 
----

Atomic Design
Para el desarrollo visual de POGO RAMEN hemos aplicado la metodología de Atomic Design, ya que nos permite construir la interfaz de forma ordenada, reutilizable y coherente. Al tratarse de un restaurante temático con una experiencia de pedido personalizada, necesitábamos un sistema visual que no dependiera solo de pantallas aisladas, sino de componentes que pudieran repetirse en distintas partes del producto: carta, creación del plato, carrito, login y sistema de fidelización.

La elección de diseño parte de la identidad del proyecto: un restaurante de ramen y poke inspirado en una experiencia de juego, donde el usuario crea su propio “equipo de 6” ingredientes. Por eso, los colores principales se han tomado de la estética del logo y del concepto del proyecto: el rojo se utiliza para acciones importantes y llamadas a la acción, el azul para navegación y estructura, el amarillo para recompensas y medallas, y los tonos crema para mantener una base cálida relacionada con la comida japonesa.

En los átomos se han definido los elementos mínimos de la interfaz, como botones, chips, campos de texto, medallas, iconos y slots de ingredientes. Estos elementos son la base del sistema y permiten mantener consistencia visual en todas las pantallas. Por ejemplo, los slots representan los huecos del “equipo de 6”, mientras que las medallas refuerzan el sistema de fidelización.

Las moléculas combinan varios átomos para formar elementos con una función concreta, como la tarjeta de ingrediente, la línea del carrito, el selector de equipo o el botón de inicio de sesión. Estas piezas ayudan a que el usuario pueda comparar, seleccionar y revisar información de forma rápida, sin perder claridad.

Los organismos agrupan moléculas para formar bloques completos de la interfaz, como el sistema PC, el constructor del equipo de 6, el carrito o la tarjeta de medallas. Estos organismos representan las partes principales de la experiencia de usuario y conectan la temática del restaurante con acciones reales: elegir comida, confirmar un pedido o consultar recompensas.
